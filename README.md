# CodeAlpha_StudentGradeTracker

Project Name:
Student Grade Tracker

Description:
Student Grade Tracker is a console-based Java application developed to manage student records and grades. The program allows users to add, view, search, update, and delete student records. It also generates a statistics report including average marks, highest marks, lowest marks, and top-performing students.

Features:
- Add Student
- View All Students
- Search Student by ID
- Update Student Marks
- Delete Student Record
- Automatic Grade Calculation (A, B, C, D, F)
- Statistics Report
- Console-Based Interface
- Input Validation
- ArrayList Data Storage
- Object-Oriented Programming (OOP)

Technologies Used:
- Java
- ArrayList
- Classes and Objects
- Loops
- Conditional Statements
- Methods
- Scanner Class

Grade Criteria:
A : 90 - 100
B : 80 - 89
C : 70 - 79
D : 60 - 69
F : Below 60

Project Structure:
Student.java
StudentGradeTracker.java
README.txt

How to Run:
1. Open the project in IntelliJ IDEA, Eclipse, or VS Code.
2. Compile the Java files.
3. Run the StudentGradeTracker class.
4. Use the menu options to manage student records.

Learning Outcomes:
- Understanding Object-Oriented Programming (OOP)
- Working with ArrayList Collections
- Implementing CRUD Operations
- Applying Java Control Statements
- Building Console-Based Applications
- Generating Statistical Reports
